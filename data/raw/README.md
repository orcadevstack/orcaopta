This folder contains raw, unmodified datasets used by the Orcaopta ML pipeline.

Guidelines:
- Do not edit raw data manually.
- Store small datasets only (GitHub-friendly).
- Large datasets should be stored in cloud storage (S3, Blob, GCS).
- Raw data is the single source of truth for preprocessing.

Examples:
- cloud_metrics_raw.csv
- user_activity_logs.json
- system_events.csv
