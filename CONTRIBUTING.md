# Contributing to Orcaopta

Thank you for your interest in contributing to **Orcaopta — the Autonomous Multi‑Cloud SRE & Healing Platform**.  
We welcome contributions from developers, cloud engineers, SREs, AI researchers, and anyone passionate about reliability, automation, and intelligent cloud systems.

This document explains how to contribute, how to report issues, how to submit pull requests, and the standards we follow across the project.

---

##  Overview

Orcaopta is a multi‑module project that includes:

- Multi‑cloud audits (OpenStack, OVN, Ceph, Kubernetes, Terraform)
- Unified cloud graph engine
- AI reasoning agent
- Autonomous self‑healing controller
- ML anomaly detection & forecasting
- RL autoscaling agents
- FastAPI backend
- Streamlit dashboard
- Terraform & Helm deployment configs

Contributions can be made to any part of the system.

---

##  Ways to Contribute

You can contribute by:

- Fixing bugs  
- Improving documentation  
- Adding new cloud audits  
- Enhancing the unified cloud graph  
- Improving the AI healing agent  
- Adding ML/RL models  
- Improving dashboard visualizations  
- Writing tests  
- Suggesting new features  
- Participating in Discussions  

All contributions are welcome.

---

##  Reporting Issues

Use **GitHub Issues** to report:

- Bugs  
- Incorrect healing actions  
- Audit false positives  
- Dashboard problems  
- Performance issues  
- Security concerns  
- Feature requests  

When reporting a bug, include:

- Steps to reproduce  
- Expected behavior  
- Actual behavior  
- Logs or screenshots  
- Environment details (OpenStack version, K8s version, Terraform version, etc.)
